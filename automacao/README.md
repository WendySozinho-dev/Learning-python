# organizadorNGC

> O programa automatiza o trabalho de separar e organizar séries de um diretório catastrófico

---

## funcionalidades

* automação de arquivos.
* não há necessidade de armazenamento extra para mover.
* rápido.

---

## Atenção!

Para usuários android, se executarem o programa, provavelmente o files by google mostrará que nada foi mudado.
Para esse cenário, basta reiniciar o smartphone e entrar novamente no files by google, dependendo da quantidade de arquivos, o celular dará uma esquentada por uns segundos.
Mesmo que o processo leve uns meros segundos, por favor, não desligue o aparelho da fonte de eletricidade, para seu próprio bem já que nenhuma cópia de segurança é realizada.

---

## Pré requisitos

Para poder usar esse script dever ter:

* python 3
* um emulador de terminal (para os usuarios de android)

---

## como usar

1. clona esse repositório
2. abra o terminal e rode o script
